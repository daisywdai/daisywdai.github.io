# Fonts

Both typefaces are open source under the SIL Open Font License 1.1 and are served from this folder, so the site makes no requests to outside font services.

- `merriweather-variable.woff2`, `merriweather-variable-italic.woff2`: Merriweather, body text. License in `OFL-Merriweather.txt`.
- `figtree-variable.woff2`: Figtree, used for the name, the navigation, and headings. License in `OFL-Figtree.txt`.

Latin character set only. If a name with characters outside Latin-1 is ever added to the site, check that it renders in these fonts.
